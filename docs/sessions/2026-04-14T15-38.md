## 1. Goals

- Resolve `YFinanceDataSource.get_price` protocol violation by renaming `as_of` to `date`.
- Ensure all tests pass after the change.
- Release a new patch version of the package.

## 2. Work Done

- **Reproduction**: Created `reproduce_issue.py` to confirm `TypeError` when calling `get_price(ticker, date=some_date)`.
- **Code Change**:
    - Renamed `as_of` to `date` in `YFinanceDataSource.get_price` in `src/py_yfinance/source.py`.
    - Refactored `src/py_yfinance/source.py` to use `import datetime` and update all `date`/`timedelta` references to `datetime.date` and `datetime.timedelta` to avoid shadowing the `date` parameter.
- **Testing**: Updated `tests/test_coverage_gaps.py` to use the `date` keyword argument.
- **Verification**: Ran `pytest` and the reproduction script to confirm the fix and ensure no regressions.
- **Documentation**: Updated `CHANGELOG.md` with the new version `0.1.12`.
- **Release**: Used `oss.py` to release `v0.1.12` to PyPI and create a GitHub Release.

## 3. Decisions Made

| Decision | Rationale |
|----------|-----------|
| Renamed `as_of` to `date` | To strictly comply with the `DataSource` protocol in `pydantic-market-data`, which other implementations (like `FTDataSource`) follow. |
| Switched from `from datetime import date` to `import datetime` | To allow using `datetime.date` inside methods where the parameter is also named `date`, avoiding shadowing and `NoneType` errors (e.g., `date.today()` would fail if the parameter `date` was `None`). |
| Automated release with `oss-package-engineer` | To ensure consistent quality gates (tests, linting, formatting) and follow established release patterns. |

## 4. Decisions Refused / Alternatives Rejected

| Rejected Approach | Reason |
|-------------------|--------|
| Keeping `as_of` and adding a compatibility shim | Direct protocol compliance is preferred for clarity and consistency across all `pydantic-market-data` providers. |
| Using a different parameter name (e.g., `as_of_date`) | The protocol explicitly specifies `date`. |
